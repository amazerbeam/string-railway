## New conventions for future contributors

- **`csc.rsp` beside an `.asmdef`** is how nullable (or any per-assembly compiler option) is set on the Unity side — an `.asmdef` file has no such field.
- **`LangVersion 9.0`** is the ceiling for any engine-free `.csproj` until the Unity 6.8 CoreCLR cutover — it must never be more permissive than what Unity's Mono compiler accepts.
- **`Directory.Build.props`** at `unity/` redirects MSBuild output away from `Assets/`, so a hand-written `.csproj` living beside an `.asmdef` never produces a DLL Unity would import as a plugin.
- **Every new engine-free assembly's `.csproj` gets added via `dotnet sln add`** to `unity/TechDuinn.FastGate.sln` — the solution is the one argument the fast gate command takes, and a missing entry means the project is silently never built.
- **A golden vector changes only when the prototype changes.** The PRNG's test vectors are generated from `prototype/src/hunt/seededRng.ts`, not from the C# port — regenerate them from the prototype if its arithmetic ever changes, never by re-running the port and copying its own output.
