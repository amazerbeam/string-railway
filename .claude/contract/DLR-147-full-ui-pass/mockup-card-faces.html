The Hunt — every card

Thirty-three cards, read by two signals. A painting means the card has a character — the five acting ranks (1, 3, 5, 9, 11) and the Treasure (7), whose treasure differs by suit: harp, chalice, sword. The border says whether it acts — solid for the five that do, dashed plus a “no rule” mark for the Treasure, which is illustrated but inert. Plain numbers carry pips. No rule text is printed — hover, focus or tap a card for the tooltip.

Notes

  • Two signals, not one. Art marks a card with a character; the border marks whether it acts. The Treasure is the case that needs both — it is a real named card from the deck and deserves a painting, but it does nothing, so it keeps the dashed border and the “no rule” mark. You can still tell at a glance which cards in a hand can change anything.
  • Rank 8 has no art, deliberately. Not because it is inert — the Treasure is inert and is painted — but because it has no settled name, so there is no character to paint yet. Give it a name and it should get a picture.
  • The figures are hand-drawn SVG silhouettes — swan, fox, axe, witch, crown — lit from behind and set in a suit-tinted vignette, with sparks for Bells, snow for Keys and stars for Moons. They are compositional placeholders: they show the pose, the crop and how much of the face a painting gets. They are not final art.
  • No printed rule. Tooltips carry it, as you asked. The demo tooltip fires on hover, focus and tap — worth keeping all three: touch has no hover, so a rule reachable only by hovering is unreachable on a phone.
  • Rank 8’s name is still unresolved and I have not picked one. the-hunt.md logs the rename as open, src/warCouncil/types.ts calls it Poison, the doc calls it Timebomb — which collides with the Timebomb buff. Labelled “rank 8” here.
